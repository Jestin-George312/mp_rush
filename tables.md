# APMS Database Schema: All Tables

This document provides a comprehensive overview of all database tables in the Academic Project Monitoring System (APMS) as of the current implementation.

## 1. Core Identity & Infrastructure

### `users`
Stores authentication and base role information for all participants.
- **Columns**: `uid` (PK), `email`, `password`, `role`, `provider`, `batch_id` (FK), `temp_guide_id` (FK), `created_at`.

### `profiles`
Extended user information for public display and internal management.
- **Columns**: `u_id` (FK), `full_name`, `avatar_url`, `phone`, `bio`, `location`.

### `departments`
Academic units within the institution.
- **Columns**: `id` (PK), `name`, `coordinator_id` (FK), `created_at`.

### `batches`
Academic cycles or student cohorts.
- **Columns**: `id` (PK), `name`, `coordinator_id` (FK), `department_id` (FK), `start_year`, `end_year`, `is_active`, `topic_submission_start`, `topic_submission_end`, `project_type_mode`, `created_at`.

## 2. Project Organization

### `groups`
Project teams formed by students.
- **Columns**: `id` (PK), `group_name`, `batch_id` (FK), `guide_id` (FK), `created_at`.

### `group_members`
Mapping of students to project groups.
- **Columns**: `group_id` (FK), `student_id` (FK), `is_leader`.

### `projects`
Official project proposals and current status.
- **Columns**: `id` (PK), `group_id` (FK), `title`, `domain`, `description`, `status` (pending/approved/rejected/completed), `progress`, `submitted_by` (FK), `review_state`, `topic_feedback`, `topic_reviewed_at`, `github_repo`, `created_at`, `updated_at`.

## 3. Project Management

### `tasks`
Kanban board items for tracking group progress.
- **Columns**: `id` (PK), `project_id` (FK), `title`, `priority`, `status` (todo/inprogress/done), `deadline`, `assigned_to` (FK), `created_by` (FK), `created_at`.

### `documents`
Academic deliverables (SRS, Reports, etc.).
- **Columns**: `id` (PK), `project_id` (FK), `uploaded_by` (FK), `name`, `file_path`, `type`, `status`, `feedback`, `reviewed_by` (FK), `reviewed_at`, `deadline_id`, `created_at`.

### `meetings`
Scheduled interactions between guides and groups.
- **Columns**: `id` (PK), `project_id` (FK), `group_id` (FK), `requested_by` (FK), `title`, `date`, `time`, `duration`, `agenda`, `meet_link`, `status`, `minutes`, `created_at`.

## 4. Academic Lifecycle & Evaluation

### `deadlines`
Global milestones set by coordinators for specific batches.
- **Columns**: `id` (PK), `batch_id` (FK), `title`, `description`, `due_date`, `phase`, `created_by` (FK), `created_at`.

### `rubrics`
Evaluation templates defined by coordinators.
- **Columns**: `id` (PK), `name`, `created_by` (FK), `total_score`, `criteria` (JSONB), `batch_id` (FK), `deadline_id` (FK), `created_at`.

### `evaluation_scores`
Scores assigned to groups based on rubrics.
- **Columns**: `id` (PK), `rubric_id` (FK), `group_id` (FK), `evaluated_by` (FK), `scores` (JSONB), `total`, `created_at`.

### `extension_requests`
Requests from students for adjusted deadlines.
- **Columns**: `id` (PK), `group_id` (FK), `deadline_id` (FK), `requested_by` (FK), `reason`, `proposed_date`, `status`, `reviewed_by` (FK), `reviewed_at`, `created_at`.

### `group_deadline_overrides`
Approved adjustments to global deadlines for specific groups.
- **Columns**: `id` (PK), `group_id` (FK), `deadline_id` (FK), `effective_date`, `extension_request_id` (FK).

## 5. Communication & Interaction

### `group_invitations`
Invitations sent between students to form groups.
- **Columns**: `id` (PK), `group_id` (FK), `inviter_id` (FK), `invitee_id` (FK), `status` (pending/accepted/declined), `created_at`.

### `notifications`
System alerts for various user actions.
- **Columns**: `id` (PK), `user_id` (FK), `type`, `title`, `message`, `ref_type`, `ref_id`, `is_read`, `created_at`.

### `messages`
Real-time chat history for project groups.
- **Columns**: `id` (PK), `group_id` (FK), `sender_id` (FK), `text`, `created_at`.

## 6. AI Engine Data

### `ai_alerts`
Proactive alerts generated by AI analysis.
- **Columns**: `id` (PK), `target_role`, `target_user` (FK), `alert_type`, `severity`, `title`, `message`, `ref_type`, `ref_id`, `is_read`, `is_resolved`, `created_at`.

### `ai_predictions`
Computed risk scores and health projections.
- **Columns**: `id` (PK), `entity_type`, `entity_id`, `risk_score`, `risk_level`, `factors` (JSONB), `predicted_at`.

### `ai_audit_log`
Historical record of AI engine decision-making.
- **Columns**: `id` (PK), `action`, `entity_type`, `entity_id`, `details` (JSONB), `performed_at`.

### `ai_config`
Operational parameters for the AI engine.
- **Columns**: `key` (PK), `value` (JSONB), `updated_at`.
